# AimLog

Shooting-sports performance tracker — **Track. Improve. Perform.**

## Run

```bash
cd aimlog
node server.js
```

Open **http://localhost:3000**

No npm install required (pure Node.js).

## Features

- Email/password auth (private per-user data)
- Practice sessions with individual shots **0–10.9** (decimals)
- Competitions with final score, rank, coach comments
- Dashboard, statistics, history, detail, edit & delete
- Dark cyber theme, responsive (desktop sidebar + mobile bottom nav)

## Data

Stored in `aimlog-data.json` next to the server.
